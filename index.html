Process Automation · Financial Controls

Financial Data Visibility Through Controlled Automation (Personal)

How much should be automated, and how much should stay under human review?

Before: every receipt was read, interpreted, and entered by hand, so expense records were fragmented and financial visibility was delayed.

After: structured input, automatic recording, review by exception
STEP 1Receipt uploaded with a standard file name
STEP 2Fields read from the name and recorded automatically
STEP 3Human checks only exceptions: foreign currency, bad format, risky classifications
  • Invalid file names are skipped, and foreign currency amounts are flagged for manual review.
  • Each receipt is tracked by its Google Drive file ID, so duplicates update the existing row.
  • The script fills only empty fields. Manual edits are never overwritten.

Key Insight: Full automation was the wrong goal. Amounts, dates, and classifications flow into the financial statements, and OCR errors can distort them. So routine work is automated, and people review only the exceptions.
